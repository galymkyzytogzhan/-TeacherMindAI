# TeacherMind AI прототипі

## Іске қосу

1. Компьютерде Node.js орнатылғанын тексеріңіз.
2. `Іске қосу.bat` файлын екі рет басыңыз.
3. Қара терезеде көрсетілген `http://localhost:8000` мекенжайын браузерде ашыңыз.
4. Серверді тоқтату үшін қара терезеде Ctrl+C басыңыз.

## Деректер және көрсетілімдік режим

- Мұғалім тіркелгілері мен жұмыс деректері осы браузердің `localStorage` жадында сақталады. Әр тіркелгінің деректері жеке кілттерде сақталады; ескі `tm_*` деректері бірінші тіркелгіге көшіріледі, ал бастапқы кілттер жойылмайды.
- Кіру және тіркелу — тек жергілікті көрсетілімдік үлгі. Құпиясөздің өзі сақталмайды; тек PBKDF2 арқылы жасалған тексеру мәні сақталады. Дегенмен бұл серверлік аутентификация емес және өндірісте пайдалануға жарамайды.
- «Құпиясөзді ұмыттыңыз ба?» әрекеті осы нұсқада тек шектеу туралы хабарлама көрсетеді. Қалпына келтіру үшін серверлік пошта қызметі қажет.
- Педагогикалық талдау — сыртқы AI қызметіне қосылмаған жергілікті ережелік көрсетілім. Ол нақты модельдің қорытындысы болып саналмайды.
- Оқушы деректерін демонстрациялық ортада нақты аты-жөнімен енгізбеңіз.

## Өндірістік нұсқаға қажет интеграциялар

Қауіпсіз іске қосу үшін серверлік аутентификация, рөлдер мен сессияны басқару, рұқсаттарды тексеретін API және қорғалған дерекқор керек. Нақты AI талдауын қосқанда сұрауларды сервер арқылы жіберіп, құпия кілттерді браузерге шығармау қажет. Қазір бұл қызметтер қосылмаған; ешқандай сыртқы API мекенжайы немесе ақылы қызмет бапталмаған.
